# Cheat sheet snippets

Quick-reference snippets from the **[Ansible Cheat Sheet](https://computingforgeeks.com/ansible-cheat-sheet/)** article.

Populated with small, copy-pasteable files organized by theme:

- `adhoc.sh` — common ad-hoc command patterns
- `playbook-skeleton.yml` — minimal viable playbook
- `inventory-patterns.ini` — static inventory examples
- `vault-commands.sh` — vault CLI reference
- `galaxy-commands.sh` — collection and role management

Files are added as the cheat sheet article is refreshed.
