# Pillar page code

Code and configuration referenced by the pillar article:
**[Ansible Automation Guide: From Basics to Production](https://computingforgeeks.com/ansible-automation-guide/)**

The pillar article links out to every article in the series. This folder hosts the small reference snippets the pillar page itself references (e.g., the example project skeleton, the shared `ansible.cfg`, and the starter inventory layout).

Nothing runnable lives here on its own — for runnable playbooks, go to the track folder that matches the article you're reading.
